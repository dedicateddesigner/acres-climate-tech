# ACRES — Brand & Design Direction

## Brand essence

Material + Science + Agriculture.

The visual language should connect geological material, carbon, soil, agriculture and living land.

## Visual narrative

Deep time
→ geology
→ rock
→ carbon
→ soil
→ living land
→ agriculture
→ measurable impact

## Core colour system

- Fossil Light
- Basalt Grey
- Carbon Black
- Soil Brown
- Living Green

Living Green should function as the primary accent for actions, highlights and regenerative outcomes.

## Typography

Headings:
Sora

Body / navigation / data:
Inter

## Visual characteristics

- Strong hierarchy
- Generous whitespace
- Material contrast
- Editorial composition
- Scientific credibility
- Agricultural context
- Controlled motion
- Contextual data visualization
- Authentic photography
- Avoid generic sustainability imagery

## Identity

The ammonite/geological symbol should be treated as a meaningful brand device rather than decorative repetition.

## Motion

Motion should communicate transformation, process and geological/agricultural relationships.

Avoid animation for animation's sake.

Prefer:
- Scroll-driven storytelling
- Controlled reveals
- Material transitions
- Process visualization
- Subtle interaction feedback

## Design quality

The website should feel:
- Contemporary
- Premium
- Intelligent
- Grounded
- Credible
- Human

It should not feel:
- Generic SaaS
- Generic environmental NGO
- Template-driven
- Overly futuristic
- Excessively animated
